# 💼 Design Profissional

Esta pasta reúne as atividades desenvolvidas na disciplina de Design Profissional, com foco na apresentação profissional, organização e utilização do GitHub como ferramenta de divulgação de conhecimentos e projetos.

## 📚 Atividades

### Etapa 1 — Pesquisa e análise de perfis profissionais

Pesquisa e análise de pelo menos 10 perfis do GitHub relacionados à área de Inteligência Artificial, observando a apresentação dos usuários, a organização dos repositórios e a documentação dos projetos.

### Etapa 2 — Organização profissional do GitHub

Atividade voltada à aplicação das práticas observadas durante a pesquisa, considerando a organização e documentação dos projetos acadêmicos no GitHub.
