# Etapa 2 — Organização profissional do GitHub

**Disciplina:** Design Profissional

**Aluno:** Thiago Oliveira

## Objetivo

Aplicar boas práticas de organização e apresentação profissional no GitHub, utilizando os conhecimentos observados na pesquisa da Etapa 1.

## Atividades desenvolvidas

### 1. Identificação do perfil

Organização das informações de apresentação, incluindo nome, descrição profissional, formação acadêmica e formas de contato.

### 2. Apresentação dos projetos

Organização dos projetos acadêmicos, utilizando nomes claros e descrições que facilitem a compreensão dos trabalhos.

### 3. Documentação dos repositórios

Utilização de arquivos README.md para apresentar os objetivos dos projetos, as tecnologias utilizadas e as instruções para execução.

### 4. Organização dos arquivos

Utilização de pastas para separar os projetos e arquivos necessários para manter os repositórios organizados.

### 5. Recursos do GitHub

Aplicação de recursos como LICENSE, .gitignore, tópicos e repositórios fixados.

## Projeto acadêmico utilizado

O projeto Conversor de Temperatura em C foi escolhido para demonstrar a aplicação das práticas de documentação e organização.

## Conclusão

A etapa permitiu aplicar práticas de organização e documentação no GitHub, tornando os projetos acadêmicos mais fáceis de entender e consultar.
