## 🎯 Objetivo do Programa

O objetivo deste programa é criar uma calculadora usando o Flowgorithm,
colocando em prática os conhecimentos de lógica de programação
aprendidos durante a disciplina.

## ⚙️ Como funciona

A calculadora possui 20 operações diferentes. O usuário escolhe a
operação que deseja realizar e informa os valores necessários.

Depois disso, o programa realiza o cálculo e mostra o resultado na tela.

Além das operações matemáticas, o programa também possui as funções
de cálculo de IMC e cálculo de área.

## 📋 20 Operações implementadas

1. **Soma** – soma dois números.
2. **Subtração** – subtrai dois números.
3. **Multiplicação** – multiplica dois números.
4. **Divisão** – divide dois números.
5. **Módulo** – mostra o resto da divisão.
6. **Potenciação** – calcula a potência de um número.
7. **Maior** – verifica qual número é maior.
8. **Menor** – verifica qual número é menor.
9. **Maior ou igual** – compara dois números.
10. **Menor ou igual** – compara dois números.
11. **Igualdade** – verifica se os números são iguais.
12. **Diferença** – verifica se os números são diferentes.
13. **Média** – calcula a média de dois números.
14. **Máximo** – mostra o maior valor entre dois números.
15. **Mínimo** – mostra o menor valor entre dois números.
16. **Distância** – calcula a distância entre dois valores.
17. **Soma dos quadrados** – soma o quadrado de dois números.
18. **Média dos quadrados** – calcula a média dos quadrados de dois números.
19. **IMC** – calcula o Índice de Massa Corporal.
20. **Área** – calcula a área de figuras geométricas.

## ⚖️ Função de IMC

A calculadora possui uma função para calcular o IMC.

Para fazer o cálculo, o usuário informa o peso e a altura.

A fórmula utilizada é:

**IMC = peso / (altura × altura)**

## 📐Função de cálculo de área

O programa também possui uma função para calcular áreas.

É possível escolher entre algumas figuras geométricas, como:

- Círculo
- Quadrado
- Retângulo
- Triângulo

Depois de escolher a figura, o usuário informa as medidas necessárias
e o programa mostra o resultado.

## Como executar

1. Baixe o arquivo da calculadora.
2. Abra o arquivo no Flowgorithm.
3. Execute o programa.
4. Escolha uma das operações disponíveis.
5. Informe os valores solicitados.
6. Veja o resultado apresentado pelo programa.
